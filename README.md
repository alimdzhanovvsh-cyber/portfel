# Шахабиддин кары Алимджанов — Жеке портфолио

Бул сайт HTML + CSS + JavaScript менен жасалган заманбап **книжный / editorial** стилдеги жеке портфолио.

## Өзгөчөлүктөрү
- Книжный (editorial) визуалдык стиль
- Билим жана иш тажрыйбасында: **алды менен мекеме/кызмат аталышы, андан кийин жылдары**
- Responsive дизайн
- Light / Dark режим
- Smooth scroll жана активдүү навигация
- Анимацияланган бөлүмдөр
- Галереядагы lightbox
- Басып чыгаруу / PDF үчүн print режим
